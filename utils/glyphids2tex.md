## 📄 `glyphids2tex.md` — Glyph-ids to LaTeX Generator

### 🌟 Purpose

This script generates a LaTeX file (`glyphids.tex`) from the glyph-ids listed
in the index file inside a directory created by `extract_typoglyphs.py`.

---

### 🚀 Usage

```bash
python glyphids2tex.py <extract_output_directory>
```

- `extract_output_directory`: directory generated by `extract_typoglyphs.py`,
  containing PNG files and an index file named after the directory
  (e.g., for directory `myglyphs/`, the index is `myglyphs/myglyphs.csv`).

---

### 📦 Output

- A single file `glyphids.tex` is created inside the same directory.
- The `.tex` file contains:
  - A preamble (`\glpismo`)
  - Comment lines with consecutive numbers
  - Each glyph identifier wrapped in a `\PTglyphid{<glyph-id>}` command
  - A postamble line (`// \endgl \xe`)
  - An Emacs local variables block

Example fragment:

```latex
\glpismo
% 1
\PTglyphid{t39_l02g01}
% 2
\PTglyphid{t39_l02g02}
// \endgl \xe
%%% Local Variables:
%%% mode: latex
%%% TeX-engine: luatex
%%% TeX-master: shared
%%% End:
```

---

### ⚙️ Processing Rules

- The index file `<dirname>.csv` is read to obtain glyph-ids.
- Glyph-ids are processed in the order they appear in the index file.
- Each glyph-id is output with its line number comment and a `\PTglyphid{}` macro.

---

### 🔢 Version

The script reports its version (e.g., `v1.0.0`) at startup.
