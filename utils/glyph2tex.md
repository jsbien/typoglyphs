## 📄 `glyph2tex.md` — Glyphs to LaTeX Generator

### 🌟 Purpose

This script generates a single LaTeX file (`glyphs.tex`) from the PNG glyphs
inside an output directory created by `extract_typoglyphs.py`.

---

### 🚀 Usage

```bash
python glyph2tex.py <extract_output_directory>
```

- `extract_output_directory`: directory generated by `extract_typoglyphs.py`,
  containing `.png` files and an index file named after the directory
  (e.g., for directory `myglyphs/`, the index is `myglyphs/myglyphs.csv`).

---

### 📦 Output

- A single file `glyphs.tex` is created inside the same directory.
- The `.tex` file contains:
  - Standard LaTeX preamble (`\exdisplay \bg \gla`)  
  - Each glyph file referenced with `\PTglyph{5}{<filename>}`  
  - A postamble with editor hints

---

### ⚙️ Processing Rules

- Input files are determined from the directory’s index file (`<dirname>.csv`).
- Only `.png` image paths from the index file are included.
- The order of glyphs in `glyphs.tex` follows the order in the index file.

---

### 🔢 Version

The script reports its version (e.g., `v1.3.0`) at startup.
